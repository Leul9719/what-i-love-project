# 📱 What I Love

A personal website about my passion for **phones and mobile technology**.

This project was created as part of my web development learning journey. Instead of building a website around a random topic, I decided to build something around an interest I genuinely enjoy: smartphones, their designs, cameras, processors, displays, software, and the stories behind them.

## 🌐 Website

The website contains four main pages:

* **Home** — Introduces the website and gives an overview of my interest in mobile technology.
* **About** — Tells the story of how my interest in phones developed.
* **Gallery** — Highlights interesting phones and memorable stories from the world of mobile technology.
* **Contact** — Contains a form where visitors can share their own phone preferences and interests.

## 🛠️ Technologies Used

* **HTML5** — Used to create the structure and content of the website.
* **CSS3** — Used for styling, layout, animations, and responsive design.
* **Font Awesome** — Used for icons in the website.
* **Git & GitHub** — Used for version control and hosting the project.

## 📱 Responsive Design

The website is designed to work on different screen sizes.

On smaller screens:

* The navigation changes into a hamburger menu.
* Content cards are stacked vertically.
* The hero section becomes centered.
* Font sizes and spacing are adjusted for smaller displays.

The hamburger menu is implemented using **HTML and CSS without JavaScript**. A hidden checkbox is used to control the menu state, while the CSS `:checked` selector displays the navigation when the hamburger icon is clicked.
